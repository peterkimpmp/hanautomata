## v0.3.0 (2026-10-09 · Windows 1대 · 비공개 모델)

원격 데스크톱으로 접속한 클라우드 가상 PC 1대에서 소스를 빌드·검사·설치했습니다. 통계 표는 당시 비공개 코퍼스 모델이었습니다.

| 확인 항목 | 결과 · 범위 |
|---|---|
| .NET Framework 빌드·단위 단언 | 25,275/25,275 통과 |
| 한글·영문 표본 1,000×2 | 한글 990 변환·오변환 1 / 영문 987 보존·보류 10·오변환 3 |
| Windows 기능 검사 | 101/101 통과 — TextBox·RichTextBox, 일반 가상 키·Unicode, F2 교체, Shift+F2 변환·되돌림·빈 선택, 학습, 후크 강제 제거 후 복구 |
| Raw Input 감시 | 이 PC에서는 등록 뒤 후크 호출이 오지 않아 **감시 호환모드**로 자동 전환(최초 검사 100개 중 68개 실패 → 보완 뒤 101/101). 다른 PC의 재현 여부·원인은 미확인 |
| 설치 | 0.2.0.0 → 0.3.0.0 · 검사본과 설치본 SHA-256 일치(`02FD3C96…42BB52`) · 학습·설정·자동 시작 보존 |
| 설치본 연습창 | 선택 후 Shift+F2로 `dkssudgktpdy` ↔ `안녕하세요` 왕복 관측 |

기능 검사는 전용 WinForms 시험창의 자동 입력입니다. **물리 키보드와 실제 앱(브라우저·채팅·편집기)의 최종 표시 결과는 확인하지 않았습니다.**

## 검증하지 않은 것

- 실물 PC(가상 PC·원격 데스크톱이 아닌)에서의 물리 키보드 입력과 Raw Input 감시의 실제 재설치.
- 브라우저·채팅·IDE 등 실제 앱 5종 이상에서의 최종 표시 결과.
- 서명된 배포본. 베타 빌드는 "알 수 없는 게시자" 경고가 납니다.
- 일반 문장 정확도 추정치. held-out 수치는 단어 단위 회귀 게이트이며 실사용 정확도가 아닙니다.
