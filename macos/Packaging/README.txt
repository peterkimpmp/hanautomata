다듬 macOS

macOS 14 이상 · Apple Silicon 및 Intel · 무료 오픈소스

설치
1. ZIP과 함께 제공된 .sha256 파일로 다운로드를 확인합니다.
2. ZIP을 풀고 Install.command를 실행합니다. 관리자 권한은 필요 없습니다.
   설치 위치: ~/Library/Input Methods/Hanautomata.app
   이전 앱은 ~/Library/Application Support/Hanautomata/Backups/에 보관합니다.
   학습 단어와 사용자 설정은 유지합니다. 실행 중인 이전 입력기를 종료하지 못하면 교체를 중단합니다.
   Terminal에서 실행하려면: /bin/sh <압축을 푼 폴더>/Install.command
3. macOS가 실행을 막으면 시스템 설정 > 개인정보 보호 및 보안에서
   다듬의 '확인 없이 열기'를 선택합니다. 이 묶음의 서명/공증 상태는 출시 안내에서 확인하세요.
4. 처음 설치할 때 시스템 설정 > 키보드 > 입력 소스 > 편집 > + > 한국어 > 다듬을 추가합니다.
   갱신한 경우 다른 입력 소스로 바꾼 뒤 다시 다듬을 선택합니다.
   여전히 이전 판이 나오면 작업을 저장하고 로그아웃·로그인합니다.

자동 띄어쓰기
입력 메뉴 또는 설정 > 입력 > 자동 띄어쓰기에서 끄고 켭니다(기본 켬).
할수있다 + Space → 할 수 있다. 조합 밑줄은 그대로 두고 후보창에서 띄어쓰기를 미리 보여 줍니다.
같은 칸에서 Space 확정 직후 15초 안에 F2를 누르면 할수있다로 돌아갑니다.
다시 F2를 누르면 기존 한↔영 전환을 합니다. 복원한 표현은 이번 실행 동안 다시 띄우지 않습니다.
전체 문장을 교정하는 모델이 아니라 공백만 넣는 14개 규칙입니다.

선택 영역 한국어 표기 검사(실험)
이 기능은 별도 검사기·사전이 포함된 묶음에서 사용할 수 있습니다.
입력 메뉴 > 선택 영역 한국어 표기 검사(실험)를 사용합니다. 자동 띄어쓰기와 별개입니다.
해당 데이터의 고지와 소스는 Hanautomata.app/Contents/Resources/proofreading/에 있습니다.
기존에 검사기가 설치되어 있으면 이를 포함하지 않은 묶음으로 갱신하지 않습니다.

확인
설정 > 정보에서 판 번호를 확인하세요. 새 빈 문서에서 '할수있다 '와 F2 두 번,
'하는것 ', '설거지 ', 한영 전환, Enter, Tab을 시험해 주세요.
앱별 입력 경로와 물리 키보드 시험 범위는 저장소 macos/COMPATIBILITY.md를 확인하세요.

이전 판으로 돌아가기
다른 입력 소스로 전환한 후 다듬을 종료합니다. Backups의 이전 Hanautomata.app을
같은 Install.command의 --app 인수로 지정하면 현재 앱도 다시 백업하면서 설치할 수 있습니다.
설정·개인 사전 파일을 지우지 마세요. 참고: https://github.com/peterkimpmp/hanautomata
