# macos — 한오토마타 macOS 입력기 (MVP·1.0 기능 구현 · 실물 검증 전)

InputMethodKit 입력기다. 판별·조합·학습은 Rust 공통 엔진([core](../core/README.md))이 맡는다. 엔진은 UniFFI 계층([ffi](../ffi/src/lib.rs))을 거쳐 Swift 셸과 연결된다. Windows 트레이 앱과 같은 판별 결과를 낸다(동등성 게이트 G1).

기능 정의서(공통 C · macOS M ID)의 macOS MVP와 1.0 기능을 코드와 자동 검사로 구현했다. 실물 키보드와 실제 앱에서 확인하는 호환 스위트(G2)는 [COMPATIBILITY.md](COMPATIBILITY.md)의 점검표로 진행한다.

## 빌드·설치·제거

```sh
cd macos
./build.sh --test       # Rust 엔진 검사 + Swift 키 매핑·엔진 연결·입력 로직 검사 → build/Hanautomata.app (이 Mac 아키텍처)
./build.sh --universal  # Apple Silicon + Intel 한 묶음
./install.sh            # ~/Library/Input Methods에 설치(관리자 권한 없음), 입력 소스 등록, 전환 키와 겹치는 macOS 설정 점검
./uninstall.sh          # 입력 소스를 끄고 앱을 지운다. 학습 파일은 남긴다
./package.sh            # 출시 묶음: universal zip + SHA-256 + Homebrew cask(build/dist/). 올리거나 게시하지 않는다
```

- **처음 설치 때 한 번 직접 추가해야 한다.** 시스템 설정 → 키보드 → 입력 소스 → 편집… → + → 한국어 → 한오토마타 순서로 추가한다. macOS 26에서 `TISEnableInputSource`가 성공을 돌려줘도 실제로 켜지지 않는 것을 확인했다(2026-10-11). `install.sh`는 실제 상태를 보고, 켜지지 않았으면 이 안내를 출력한다.
- **전환 키와 겹치는 macOS 설정**은 `install.sh`(내부적으로 `Hanautomata --check`)와 첫 실행 설정이 읽어서 알려 준다. 바꾸지는 않는다.
  - 키보드 단축키 '입력 메뉴에서 이전/다음 소스 선택'이 ⇧Space면 ⇧Space가 한오토마타까지 오지 않는다.
  - 'Caps Lock 키로 ABC 입력 소스 전환'이 켜져 있으면 시스템이 Caps Lock을 먼저 가져간다.
- 메뉴 막대에서 고정 모드 아이콘(가·A)을 보려면 '한오토마타 (한글 고정)'·'한오토마타 (영문 고정)'도 추가한다. 추가하지 않아도 모드는 바뀌고 입력 메뉴에 표시된다.
- 필요한 것: Xcode Command Line Tools(swiftc), Rust(cargo). universal 빌드는 `rustup target add x86_64-apple-darwin`이 필요하다.
- 파일은 모두 `~/Library/Application Support/Hanautomata/`에 있다. 입력기 프로세스 하나만 쓴다(C-OPS-09).

| 파일 | 내용 |
|---|---|
| `words.json` | 학습 파일. Windows 트레이 앱과 같은 문서 형식(Format 2) |
| `keep.txt` · `convert.txt` | 예외 목록(안 바꿀 단어 · 항상 바꿀 단어). 한 줄에 하나, `#` 설명. 고치면 다음 입력부터 반영 |
| `diagnostics.json` | 진단 집계. 글자 없이 횟수만(`Hanautomata --diagnose`, `--diagnose reset`) |

## 서명·배포 (M-14 · 결정 D15)

- 기본은 ad-hoc 서명이다. 직접 빌드해 설치하면 그대로 쓴다. 내려받은 zip은 Gatekeeper가 막을 수 있다. 이때는 `xattr -dr com.apple.quarantine ~/Library/Input\ Methods/Hanautomata.app`로 풀어야 한다.
- Developer ID가 생기면 다음 두 변수를 두고 `./package.sh`를 실행한다. 그러면 hardened runtime으로 서명하고, 공증한 뒤 티켓을 붙인다.
  - `HANAUTOMATA_SIGN_ID="Developer ID Application: …"`
  - `HANAUTOMATA_NOTARY_PROFILE=<notarytool store-credentials 프로필>`
- Homebrew cask 초안은 `Packaging/hanautomata.rb.in`이다. `package.sh`가 판 번호와 체크섬을 채워 `build/dist/hanautomata.rb`를 만든다. tap에 올리는 일은 별도 출시 단계다.

## 결정이 필요한 것

- **커서 앞 문맥 기본값(C-DET-08)**: held-out 측정 결과는 아래와 같다. 정의서 인수 기준은 '혼용 문장에서 오변환 증가 0'이다. 이를 넘지 못해 기본값을 껐다.

  | 앞 문장 | 한글 단어 놓침(1,000개 중) | 영어 단어 오변환(1,000개 중) |
  |---|---:|---:|
  | 없음(현행) | 15 | 0 |
  | 같은 언어 | 6 | 0 |
  | 반대 언어 | 15 | 4 |
- **서명·공증(D15)**: Apple Developer ID 연 99달러. 없으면 내려받은 zip을 Gatekeeper가 막는다.
- **⇧Space·Caps Lock을 먼저 가져가는 macOS 설정**: 사용자가 시스템 설정에서 직접 바꾼다. 한오토마타는 알려 주기만 한다.
